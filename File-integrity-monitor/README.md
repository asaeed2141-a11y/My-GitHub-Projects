# 🔐 File Integrity Monitor

A Python-based cybersecurity project that monitors files using **SHA-256 hashing** to detect unauthorised or unexpected changes.

The project provides a **Flask web dashboard** where users can create a file baseline, perform integrity checks, view detected changes, manage exclusions, and review security logs.

## 🚀 Features

* 🔑 **SHA-256 File Hashing** — Generates cryptographic hashes for monitored files.
* 💾 **Baseline Storage** — Saves a trusted baseline of file hashes using JSON.
* 🔎 **Integrity Checking** — Compares current file hashes against the saved baseline.
* 🟠 **Modified File Detection** — Detects files whose contents have changed.
* 🔵 **Added File Detection** — Detects newly added files.
* 🔴 **Deleted File Detection** — Detects files that have been removed.
* 📋 **Security Logging** — Records detected integrity changes with timestamps.
* 🚫 **File & Folder Exclusions** — Allows selected files and folders to be excluded from monitoring.
* 🌐 **Flask Web Dashboard** — Provides an easy-to-use browser interface.
* 📊 **Scan Statistics** — Displays the number of unchanged, modified, added and deleted files.
* 🛡️ **Input Validation & Error Handling** — Handles invalid paths, permissions and malformed JSON.
* 📱 **Responsive Interface** — Designed to work on desktop and smaller screens.

## 🔍 How It Works

### 1. Create a Baseline

The user selects a folder to monitor.

The application scans the files and calculates a **SHA-256 hash** for each file.

These hashes are stored as the trusted baseline.

### 2. Check File Integrity

When an integrity check is performed, the application scans the folder again and calculates new hashes.

The new hashes are compared against the baseline.

The application can identify:

* **Modified files**
* **Added files**
* **Deleted files**
* **Unchanged files**

### 3. Security Logging

Detected changes are recorded in the security log with:

* Date and time
* Event type
* File path

Example:

```text
2026-09-10 20:00:00 - MODIFIED - C:\example\test.txt
```

## 🚫 Exclusions

The application supports file and folder exclusions.

For example:

```text
Excluded files:
baseline.json
integrity.log

Excluded folders:
.git
__pycache__
```

This prevents files that are generated by the application or development environment from being monitored.

After changing exclusions, the baseline should be recreated before performing another integrity check.

## 🛡️ Security Considerations

The project includes several security-focused measures:

* SHA-256 cryptographic hashing
* Input validation
* File access error handling
* JSON error handling
* Restricted local Flask binding
* Flask secret key
* Disabled Flask debug mode
* Security event logging
* File and folder exclusions

This project is intended as an **educational cybersecurity project** and is not designed to replace enterprise-grade File Integrity Monitoring (FIM) solutions.
